# Backlog

One prototype per day, top unchecked item first. Each ships as its own PR.

Format: `- [ ] <name> | <resource URL or local file path> | <rebuild | new> | <optional note>`

For `rebuild`, `<name>` is the existing file in `registry/ui/`. The note can say where the item goes, for example the `motion/type` docs section.
